    通訊參數

    一般 USB 轉 RS485 會自動切換收發，不用勾 RTS。間隔延遲用來確保幀與幀之間有足夠的靜默時間（Modbus 規定至少 3.5 字元）。

    硬體接線

    轉接器 A(+) 接設備 A，B(−) 接設備 B，必要時共地 GND。匯流排兩端各接一個 120 Ω 終端電阻。所有設備的鮑率、校驗、停止位元要一致。

    實體連線需要用電腦版 Chrome 或 Edge 開啟本頁的 HTML 檔。
